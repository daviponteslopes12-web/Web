# Projeto Mini Catálogo

Projeto de catálogo de produtos feito para praticar e aprender novas técnologias.

---

## Stack (tecnologias utilizadas)

```
**Backend**
- TypeScript
- Express

**Frontend**
- React
- Node.js

**Banco**
- MySQL
```
---

### Rodando o projeto
1. Criar banco de dados -> *backend/src/infra/database/schema.sql*

2. Criar arquivo .env, seguir o exemplo de .env.example -> *backend/.env.example*

3. Instalar bibliotecas -> **npm i**

4. **Repetir passos 1 e 2 no frontend**


### Scripts

npm run dev -> rodar typescript (para desenvolvimento)

npm run build -> criar ./dist com projeto javascript transpilado 

npm run start -> rodar projeto javascript transpilado
